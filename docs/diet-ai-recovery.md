# AI 菜谱进度与草稿恢复

饮食页生成 AI 菜谱时，可以收起生成窗口或切换到其他页面。返回饮食页后，页面会显示进度或保留的草稿，点击“查看进度”或“查看菜谱草稿”继续操作。

本功能已合并到 `main`，包含在 v0.1.2 完整 Windows 本机版中。升级后关闭旧程序，启动新版 exe 再使用。

## 使用方式

1. 在“饮食计划 → 饮食模板”生成 AI 菜谱。
2. 生成期间点击“收起，继续生成”，或关闭窗口后切换页面。需要停止时点击“取消生成”。
3. 返回饮食页，点击进度提示中的按钮。已有草稿不会再次提交生成请求。
4. 编辑模板名称、说明、循环天数或餐食后，即使暂时离开页面，未保存内容仍保留。
5. 点击“保存模板”或“保存并导入日历”才提交内容。保存失败时保留草稿供重试，保存成功后清除本次恢复记录。

## 保存范围

- 恢复记录保存在当前浏览器标签页的会话存储，并按账号和运行模式区分。切换账号不显示另一账号的草稿。
- 共享服务及完整本机版的后台任务支持整页刷新后按原任务编号恢复，不会另起一次生成。提交响应尚未返回时，保留的请求编号用于重复提交保护。
- 服务重启或任务过期后会提示重新生成，不会假装任务仍在运行。已保存到浏览器的生成结果与编辑内容仍可继续查看。
- 普通免登录本机服务及访客浏览器直连 Ollama 的请求支持页面内导航；整页刷新会中断直连请求，此时提示重新生成。
- 关闭标签页、清除浏览器数据或更换设备后，不保证保留尚未保存的草稿。浏览器禁用会话存储时，页面内导航恢复仍可使用，刷新恢复不可保证。
- 生成结果不会自动创建正式模板、餐食或今日计划。

## 开发验证

前端回归覆盖同一任务去重、刷新重连、请求编号恢复、过期任务、显式取消、账号隔离、未保存编辑及保存失败重试。浏览器验收使用 HTTP 模拟任务与独立数据，不代表真实模型内容质量验证。

本次验证：22 项前端用例通过，TypeScript 检查与生产构建通过。Edge 浏览器中验证切页、刷新重连、草稿和编辑恢复、确认后保存；全过程仅提交一次生成、一次模板保存，没有发出取消请求，也没有页面脚本错误。
