# 自然语言条件搜索与计划实际对照

状态：已实现于 `fix/search-coverage`，包含前后端代码、测试与功能说明；未合并到主分支，现有发布包不自动更新。

## 问题

此前检查发现，便签及日常记录已成功保存，但使用其中的唯一关键词进行全局搜索时没有结果。

## 工作内容

- 将便签、日常记录纳入全局搜索。
- 搜索结果显示内容类型及必要的日期信息，并能进入对应位置。
- 沿用账号隔离，排除已删除记录。
- 支持中文相对日期、指定日期、类别、完成状态和字面关键词组合；界面展示并允许修改识别条件。
- 提供计划数、当前完成率、明确填写的预计分钟、手动学习记录、已结束专注时长和日常活动来源。
- 将未知时长与零区分，手动记录和专注计时分开；不根据日常描述自动完成任务或推算时长。
- 支持来源记录的日期、学习目标和记录页签定位及高亮。

## 验收标准

- 新建包含唯一关键词的便签、日常记录后，均可搜索到。
- 修改后的内容可以检索，删除后的内容不作为有效记录返回。
- 不影响现有计划搜索，其他账号无法搜索到本账号的数据。

## 验证记录

环境：Windows，本仓库虚拟环境、React 19、Vitest 3、Python pytest；浏览器验收使用独立的无界面 Edge 和测试账号。未使用原用户数据库。

- 后端搜索及系统功能测试：26 项通过，覆盖中文条件识别、时间边界、空值、显示上限不影响统计、删除及真实共享账号隔离。
- 前端：新增搜索面板和来源跳转共 10 项用例，最终全部通过；原今日计划、学习页、首页、日常记录及系统功能分批回归通过。回车默认动作的回归用例覆盖真实浏览器发现的弹窗误关闭问题。
- TypeScript 检查与 Vite 生产构建通过。
- 浏览器实际验收：登录、回车打开查询、学习对照、昨天运动记录、点击回到历史日期并高亮来源，通过；无页面脚本异常。
- 独立演示数据：2 项学习计划、1 项完成、手动记录 20 分钟、无已结束专注记录；页面分别显示 50% 完成率、20 分钟及“未记录”，不将活动描述计为学习时长。

入口、支持范围和限制见[功能说明](../natural-language-search.md)。这份验证不替代其他模块的完整产品验收。
