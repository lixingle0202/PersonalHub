# PersonalHub 页面与交互规格

## 1. 全局框架

- 桌面优先，适配 1440px、1024px 及 390px 窄屏；窄屏侧栏变为顶部导航，日历只在自身容器横向滚动。
- 左侧悬浮导航：总览、今日计划、学习计划、饮食计划、数据与设置；当前链接有视觉选中态及 `aria-current="page"`。
- 顶栏：页面名称、“搜索或提问”、快速新增、保存状态。
- 主区：列表、看板或周视图。
- 右侧详情抽屉：查看和编辑记录，关闭抽屉后保留列表上下文。
- 删除进入回收站；永久删除使用二次确认。
- 所有写操作显示保存中、已保存或保存失败。

### 自然语言查询与计划对照（v0.1.1）

在“搜索或提问”输入问题并按回车，打开查询弹窗。显示识别出的日期、类别、状态与关键词，支持修改后重新查询；提供“搜索结果”和“计划与实际”两个页签。

对照展示计划完成率、预计学习时长、手动记录、已结束专注计时及活动来源。缺失时长显示“未记录”，不同来源不自动相加。点击结果关闭弹窗，定位原日期或目标并高亮；加载、失败重试与无结果均有对应状态。详细范围及统计口径见[自然语言搜索](natural-language-search.md)。

### 学习趋势与饮食草稿恢复（v0.1.2）

学习页底部展示近 7 / 30 / 90 天学习趋势，可选择目标、切换手动记录或专注计时，并展开每日明细。累计分钟、区间学习天数、连续学习天数和任务完成率分别显示；未记录与明确的 0 分钟区分，结束专注或保存记录后自动更新。

饮食 AI 生成弹窗可收起，饮食页保留进度或草稿入口。返回页面或刷新后继续查看原任务；编辑后的模板名称、说明及餐食行保留在当前标签页，不自动保存为正式模板。只有确认保存或导入后写入正式数据。

### 视觉材质与可访问性

- macOS 风格的系统字体、蓝紫渐变背景、柔和圆角、细边缘高光和分层阴影。侧栏与工具栏使用半透明玻璃，正文卡片保持高不透明度，避免文字被背景干扰。
- 页面统一使用背景、导航、卡片、弹窗四层空间；悬停、按下、键盘焦点各有明确反馈。首页以日期、完成环、三项统计和计划/备忘形成阅读顺序。
- 外观设置即时同步 Ant Design 控件、日期选择、下拉框、弹窗和全局提示；主题切换保留未保存输入。深色模式使用独立材质色，不通过整体反色实现。
- 用户主题色保留，按钮与正文强调色分别生成可读色，普通文字抽查对比度至少 4.5。导航可跳到主内容，图标装饰不干扰按钮名称。
- 尊重系统减少动态效果、减少透明度和增强对比度偏好。无 `backdrop-filter` 支持时使用实色材质，功能和阅读不依赖模糊滤镜。

## 2. 路由

| 页面 | 路由 |
|---|---|
| 首页总览 | `/` |
| 今日计划 | `/today` |
| 学习计划 | `/learning` |
| 饮食计划 | `/diet` |
| 数据与设置 | `/settings` |

详情用路由查询参数表达，例如 `/learning?item=<id>`，从今日计划或搜索结果跳转后可以用浏览器返回。旧的 `/media`、`/development`、`/consulting` 和 `/games` 地址统一返回首页。

## 4. 状态契约

- 计划事项：`pending`、`completed`、`cancelled`
- 计划分组：`must`、`scheduled`、`optional`
- 优先级：`low`、`normal`、`high`、`urgent`
- 保存状态：`idle`、`saving`、`saved`、`failed`

状态只能由后端接受的枚举值产生。界面显示中文，数据库和接口使用上述固定英文值。

## 5. 摘要规则

- 今日完成率：今日已完成且未取消数量 / 今日未取消总数量；总数为 0 时显示 0%。
- 逾期：计划日期早于今天且状态为 pending。
- 即将到期：今天之后三天内到期且状态为 pending。
- 学习：显示当前日期范围内的学习目标名称和今日任务数；即使没有今日任务，也保留当前学习目标。
- 饮食：按当前时间选择下一餐，显示今日饮水量。

## 6. 删除、归档、取消和完成

- 完成：业务仍有效，但执行已结束。
- 取消：计划不再执行，保留历史原因。
- 归档：从日常活动视图隐藏，仍可查看和恢复。
- 删除：设置 `deleted_at` 并进入回收站。
- 永久删除：清除记录及其仅属于该记录的子数据，必须二次确认。

## 7. 交互状态

每个数据页面必须实现加载中、无数据、正常、保存失败和读取失败状态。失败时保留用户正在编辑的内容，允许重新保存。

## 8. 本地大模型与学习草稿

“数据与设置”新增“本地大模型”页签：Ollama 安装链接、服务地址、检查连接并刷新模型、模型选择和保存。`/settings?tab=ai` 可直接进入。无服务、无模型和保存失败均显示可操作的中文提示。

学习页面增加“AI 生成学习计划”按钮。窗口先填写主题、目标、目前基础、开始日期、1—30 天、每日分钟和补充要求。生成时显示等待状态并允许取消；未配置或无法连接时禁用生成。

成功后展示可编辑草稿，允许修改名称、目标、章节、各任务日期/标题/时长/说明和移除任务。必须确认后才加入正式学习计划。导入失败保留编辑内容可重试；导入期间禁用重复操作。当前浏览器会话刷新后读取已生成草稿，重开窗口保留尚未提交的页面编辑。
