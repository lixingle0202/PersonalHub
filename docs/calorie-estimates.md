# 热量估算如何计算

保存一餐前，编辑窗口会显示总热量、计算来源和逐项食材依据。改变菜品或用餐份数会重新估算，保存后的餐食使用同一套计算逻辑；早餐、午餐、晚餐和加餐不再影响同样食物的热量。

计算优先级如下：

1. 手动填写的整餐热量，直接作为总量。
2. 常用菜品中填写的每份热量，再乘本餐用餐份数。
3. 实际配方：各食材用量乘参考能量，合计后除以配方份数，再乘本餐用餐份数。用油和糖应计入配方。
4. 没有配方时，已支持的常见复合菜采用明确列出用量的示例配方。

参考配方目前包含190道常见家常菜、汤、主食和早餐，包括蛋炒饭、宫保鸡丁、鱼香肉丝、红烧肉、麻婆豆腐等，也识别部分常见别名。比如农家小炒肉的一份示例为五花肉120克、青椒150克、大蒜5克、食用油8克、酱油10克；页面会逐项说明热量。这些用量是项目提供的参考，不能代表某家餐馆或个人实际做法，填写实际配方后会优先按实际用量计算。

对于已支持的参考菜品，如果配方里某项缺少数量且有对应的参考用量，会标注“参考用量”；未知食材不会被忽略后给出整餐总热量，而会提示补充。未填写用油的自定义配方会提示额外用油尚未计入。食材按烹饪前可食重量计算，烹饪失水、弃去的油脂和品牌差异仍会带来误差。

新增食材参考依据包括[香港卫生署的猪肉资料](https://restaurant.eatsmart.gov.hk/eng/content.aspx?content_id=645)、[加拿大卫生部蔬菜资料](https://www.canada.ca/en/health-canada/services/food-nutrition/healthy-eating/nutrient-data/table-4-vegetables-vegetable-products-nutrient-value-some-common-foods-2008.html)、[USDA SR28 食材资料](https://www.ars.usda.gov/ARSUserFiles/80400535/Data/SR/SR28/reports/sr28fg11.pdf)和[NASA 存档中的 USDA 豆制品资料](https://ntrs.nasa.gov/api/citations/19950005719/downloads/19950005719.pdf)。代码中的食材表和示例用量保存在 `backend/app/services/food_reference.py`，可继续扩充。


一餐多种食物

一餐可同时勾选多道常用菜，也可用“添加一道菜或主食”逐行填写，两部分一起计入整餐热量。旧输入中的加号、空格、顿号、逗号、分号和换行也可分隔食物，例如 `米饭200g 西红柿炒鸡蛋`。每项可填写克数或份数，例如 `蛋炒饭200g`、`西红柿炒鸡蛋0.5份`。本餐用餐份数会再乘全部项目，填写实际食用克数时通常保持1。存在未知食物时会列出已识别小计，整餐仍标记待补充，不将部分热量当作完整总量。

按克数换算复合菜时，示例食材的可食重量合计用于近似成品重量；页面说明烹饪水分变化会影响该近似。米饭按熟饭重量计算，肉类、蔬菜等按参考配方所列状态计算；骨、壳等不可食部分不计入克数。

离线食物数据库与授权

已导入[食品药物管理署2026食品营养成分资料集](https://data.gov.tw/dataset/8543)2026-10-05版的2,213条有效每100克热量记录，2026-11-04导入。该数据依据[政府资料开放授权条款第1版](https://data.gov.tw/license)公开提供，本项目保留来源编号、样品说明、来源名称和校验值，并以OpenCC补充简体搜索名称；不代表提供机构对本项目的认可。参考配方的用量由本项目编写，与官方测量的特定食物样品区分显示。

食物库内的生食、干货、冷冻和熟食状态保留在名称和样品说明中，不做模糊替换。没有输入重量的数据库食物暂按100克一份，并明确提示修改。没有热量数据的原始记录不按0处理。旧有食物参考值和保存的实际配方优先，已有记录不会因导入而被写成另一道菜。

快照保存在 `backend/app/services/food_catalog_data.py`，搜索和精确别名映射在 `food_catalog.py`，190道配方由 `food_reference.py` 与 `common_recipes.py` 提供。运行时不需要外部营养API或额外费用。更新数据时下载资料集的官方CSV压缩包，安装仅供导入的 `opencc-python-reimplemented`，运行 `python scripts/import-food-catalog.py <CSV压缩包> backend/app/services/food_catalog_data.py` 后核对版本信息并执行 `test_food_catalog.py`。

菜名联想支持部分文字、多个关键词和常见别名，按精确匹配、开头匹配、包含匹配排列。不同别名指向同一道菜时只显示一个选项。可输入“金钱”“土豆 牛肉”等搜索；每一行都可以点选建议。选择时保留已有食物和克数，例如“米饭200g + 金钱100g”选择后变为“米饭200g + 小炒金钱蛋100g”。新增74道配方包含小炒金钱蛋、虎皮蛋、香干炒肉、大盘鸡、咖喱鸡、黑椒牛柳和多种盖饭等。
