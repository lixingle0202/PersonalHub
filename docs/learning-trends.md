# 学习趋势

学习页底部的“学习趋势”集中显示近期学习变化，可选近 **7 / 30 / 90 天**和全部目标或指定目标。

- **每日学习时长**：切换手动记录或专注计时，查看柱状图和每日明细。
- **连续学习天数**：所选来源每天有正时长即算学习一天；截至今天或昨天，连续天数可超过图表区间。
- **任务完成趋势**：每日柱形区分已完成和未完成，并汇总完成率。
- **自动更新**：添加学习记录、调整任务、结束专注后刷新统计；重新进入学习页、切回网页或点击“刷新趋势”也会重新读取。

## 统计口径

手动记录与专注计时**分别统计，不相加**，同一次学习可能在两处都记录过。每日总时长来自所选来源；“区间学习天数”只计算当前日期区间。

手动记录采用学习日期；未填写的日期显示“未记录”，明确填写 0 分钟则显示 0。专注计时只统计已结束的记录，按浏览器当前时区拆分跨午夜时段；正在计时的内容在结束后加入。跨日计时的连续天数以涉及的实际学习日期计算。

任务按**计划日期及当前完成状态**统计，并非当天实际点击完成的次数。完成、撤销、改期后对应日期会变化；未排期、已取消任务不计入完成率，无任务时显示“暂无任务”。目标百分比进度不替代任务完成率。

已删除或归档的目标、学习记录、任务，以及属于已删除或归档任务的专注计时不参与统计。未来的手动记录与任务不进入截至今天的图表。各账号沿用现有独立数据库，不能查看其他账号的趋势。

## 接口

`GET /api/v1/learning/trends?today=2026-11-07&days=7&offset_minutes=-480`

`today` 为浏览器本地日期；`days` 为 7、30 或 90；`offset_minutes` 为 JavaScript `getTimezoneOffset()` 的结果，东八区为 -480；可加 `goal_id` 限定目标。返回连续日期序列、两种时长来源的独立汇总和任务汇总，不修改数据、不调用大模型。

## 验收步骤

1. 在学习分支源码启动的网页中创建目标，打开“学习记录”，补记昨天 20 分钟、今天 30 分钟。
2. 在页底选择这个目标和“手动记录”：累计 50 分钟、区间学习 2 天、连续学习 2 天，每日明细分别为 20 和 30。
3. 安排今天两条学习任务，完成一条：任务完成率 50%，图中为已完成 1 / 计划 2。撤销完成后应降为 0%。
4. 开始并结束一次专注，切换“专注计时”：出现本次已结束时长；手动记录仍为 50 分钟。
5. 切换 7 / 30 / 90 天、目标，或离开学习页再回来，数据应保持一致；无记录的目标应展示空状态。

本功能已合并到 `main`。旧版 exe 不会自动更新；源码部署需更新代码、重新构建前端并重启服务后生效。

## 自动验收

后端：`python -m pytest backend/tests/test_learning_trends.py backend/tests/test_focus_timer.py backend/tests/test_learning_task_completion.py backend/tests/test_learning_deletion.py`

前端：在 `frontend` 目录运行 `pnpm test -- src/components/LearningTrends.test.tsx src/components/FocusTimer.test.tsx src/pages/LearningPage.test.tsx`，并运行 `pnpm build`。

真实浏览器：安装或指定 Playwright，启动使用独立数据目录的本机登录版预览，再运行 `node scripts/test-learning-trends.mjs <Playwright模块路径> http://127.0.0.1:8788 <截图目录>`。脚本注册专用测试账号，验证记录、任务、计时、切页、刷新和小屏布局，不应针对个人数据服务执行。
