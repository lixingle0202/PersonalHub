# PersonalHub 验收测试矩阵

## PRD-10.1 启动和本地运行

- `E2E-START-001`：断开外网后启动并完成主要操作。
- `SEC-LOCAL-001`：服务仅绑定 127.0.0.1。
- `E2E-START-002`：首次启动不要求账号或云配置。

## PRD-10.2 页面和导航

- `E2E-NAV-001`：五个保留的一级页面全部可访问，四个已移除地址（包含 `/games`）返回首页。
- `E2E-NAV-002`：任意一级页面可切换到其他页面。
- `E2E-NAV-003`：搜索、快速新增和保存状态可用。
- `E2E-NAV-004`：程序更新后，已打开的旧页面点击学习计划等延迟页面时会自动刷新到新版本；恢复失败时显示重新加载提示而不是空白页。

## PRD-10.3 首页

- `API-HOME-001`：日期、总数、完成数、完成率和逾期数正确。
- `API-HOME-002`：今天的学习任务和饮食安排全部进入首页今日计划，两个模块摘要统计正确，游戏计划不再出现。
- `E2E-HOME-001`：首页完成事项后统计即时更新。
- `E2E-HOME-002`：备忘可转为今日计划或模块内容。
- `E2E-HOME-003`：学习和饮食两个模块摘要均显示在“今日计划”卡片内，页面不存在独立模块摘要区或游戏摘要。
- `E2E-HOME-004`：今天要完成的学习、饮食两类具体计划全部显示，摘要和事项可跳转到正确详情。
- `API-HOME-003`：当前有效的学习目标即使没有拆分当日任务，也会出现在首页学习摘要中，未来尚未开始的目标不显示。
- `E2E-HOME-005`：首页概况只显示今日事项、已经完成和必须完成三张统计卡，不显示“逾期事项”卡。

## PRD-10.4 今日计划和跨模块同步

- `API-SYNC-001`：模块事项按计划日期进入今日计划。
- `API-SYNC-002`：今日计划完成后来源状态同步。
- `API-SYNC-003`：来源完成后今日计划状态同步。
- `API-SYNC-004`：修改日期后只出现在新日期。
- `DB-SYNC-001`：一个来源不存在重复计划记录。
- `E2E-DAY-001`：结束今日支持顺延、重新安排和取消。

## PRD-10.5 模块功能

- `E2E-LEARN-001`：拆分章节、记录任务和学习情况并计算进度。
- `E2E-LEARN-002`：点击左侧目标可修改计划信息，右侧可随时保存 0—100 的手动进度。
- `E2E-DIET-001`：按月历安排餐次并按当前月份生成可勾选购物清单。
- `API-DIET-001`：修改餐次后关联的今日计划标题同步更新，空饮食内容被拒绝。
- `E2E-DIET-002`：点击已有餐次格可修改饮食内容，点击空餐次格可按对应日期和餐次直接新建。
- `E2E-DIET-003`：周一开头的月历覆盖完整周，月份切换、回到今天、跨年和闰年边界正确；当天高亮，实际饮食可见，多餐可展开。
- `E2E-DIET-004`：单餐删除必须确认，取消不删除；删除后保留其他餐食，失败时保留原餐食和编辑窗口。
- `API-DIET-002`：编辑日期、餐次和实际饮食后，首页、今日计划和搜索同步；旧日期不再呈现该安排。
- `API-DIET-003`：删除待办/已完成餐食后，日历、首页、今日计划、搜索和逾期/即将到期统计不再呈现，其他餐食、菜品和健康记录保留，新购物清单排除该餐食食材。
- `API-DIET-004`：缺失关联 ID 或存在旧来源关联时，删除仍移除所有关联事项；从今日计划删除餐食也同步移除日历，只有显式恢复才重新呈现。
- `E2E-GAME-RETIRE-001`：左侧导航、快速新增、全局搜索、首页和今日计划均不显示游戏内容，访问旧 `/games` 地址返回首页。
- `API-GAME-RETIRE-001`：旧游戏娱乐接口不再注册，相关请求返回 404。
- `DB-GAME-RETIRE-001`：数据库从旧版本升级到 `0003` 后，现有 `game_plans` 及模块为游戏或来源为游戏计划的关联 `agenda_items` 均被软删除，非游戏事项不受影响。

## PRD-10.6 数据持久性

- `E2E-DATA-001`：刷新页面后数据存在。
- `E2E-DATA-002`：关闭浏览器后数据存在。
- `E2E-DATA-003`：重启本地服务后数据存在。
- `E2E-DATA-004`：清理浏览器缓存后数据存在。
- `FS-DATA-001`：独立数据库位于用户数据目录。

## PRD-10.7 备份、恢复和删除保护

- `API-BACKUP-001`：手动备份文件名包含时间和类型。
- `E2E-BACKUP-001`：恢复后数据与备份时一致。
- `API-BACKUP-002`：恢复前产生自动备份。
- `API-BACKUP-003`：无效备份不破坏当前数据库。
- `E2E-TRASH-001`：删除内容进入回收站且可以恢复。
- `E2E-TRASH-002`：永久删除需要二次确认。

## PRD-10.8 第一版范围

- `OFFLINE-001`：运行期间没有外部网络请求。
- `SCOPE-001`：不依赖 AI、云服务或第三方账号。
- `SCOPE-002`：不自动发布或对外发送内容。
- `SCOPE-003`：不提供附件上传。

## 测试数据原则

- 自动测试只使用临时目录和临时 SQLite 数据库。
- 备份恢复测试只替换测试数据库。
- 每个测试独立创建数据，不依赖执行顺序。
- 不允许删除、跳过或放宽失败测试来通过验收。

## PRD-11 本地 AI 学习计划

- `API-AI-001`：设置保存后重启仍可读取；只允许回环服务地址，禁用环境代理和 HTTP 重定向。
- `API-AI-002`：查询已安装模型；生成发送用户填写需求和 JSON schema，不自动读取私人笔记。
- `API-AI-003`：生成跨年计划后只有草稿，正式目标和今日计划为空；草稿可重新读取。
- `API-AI-004`：确认手动编辑的草稿后，目标、章节、任务、首页、今日计划和搜索同步；重复确认不重复创建，删除目标后不被重复确认恢复。
- `API-AI-005`：缺少计划日、章节引用错误、超出每日时间、重复任务和空标题的输出均被拒绝，数据库没有部分数据。
- `API-AI-006`：未配置、未启动、模型不存在、超时、非法 JSON 和重定向显示明确错误，不创建正式计划。
- `API-AI-007`：导入日期越界被拒绝；模拟写入失败时整笔事务回滚，重试可成功。
- `DB-AI-001`：迁移 0003 → 0004 保留已有目标，添加草稿表。
- `UI-AI-001`：检查连接、模型选择和保存可用；未配置/离线时不发生成请求。
- `UI-AI-002`：生成后预览、编辑、移除任务，只有确认才导入；失败保留草稿可重试。
- `UI-AI-003`：刷新恢复草稿，不重新生成；关闭窗口或离开页面时取消等待，不导入任务。
- `BROWSER-AI-001`：真实浏览器连接隔离 FastAPI 与模拟 Ollama HTTP 服务，配置、生成、刷新恢复、手动修改、确认导入，验证首页/今日计划/搜索和重复确认，无浏览器脚本错误。模拟服务结果不作为真实模型推理验收。
- `PACKAGE-AI-001`：独立打包版可保存模型设置并在重启后读取；实际连接未启动的本机端口返回 503，确认 HTTP 客户端依赖已打包。
