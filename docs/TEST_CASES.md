- `E2E-START-001`：断开外网后启动并完成主要操作。

## PRD-10.2 页面和导航

- `E2E-NAV-002`：任意一级页面可切换到其他页面。
- `E2E-NAV-003`：搜索、快速新增和保存状态可用。
- `E2E-NAV-004`：程序更新后，已打开的旧页面点击学习计划等延迟页面时会自动刷新到新版本；恢复失败时显示重新加载提示而不是空白页。
- `API-SEARCH-001`：识别相对日期、类别、完成状态和关键词，手动筛选覆盖识别结果；已删除数据与其他账号数据不返回。
- `API-SEARCH-002`：两条学习计划仅完成一条时完成率为 50%；预计 75 分钟与手动记录 20 分钟分别展示，无专注计时显示未记录，不凭活动描述补算。
- `E2E-SEARCH-001`：顶部回车打开查询弹窗且不被回车默认动作关闭；修改问题后展示新结果，点击历史日常记录跳到对应日期并高亮。
- `EXE-UPGRADE-001`：v0.1.1 完整 exe 使用独立数据目录完成登录、主要模块、新搜索、真实内置 AI 学习与饮食生成及导入；重启后账号、记录和模型选择保留，第二实例复用现有服务。

- `API-HOME-002`：今天的学习任务和饮食安排全部进入首页今日计划，两个模块摘要统计正确，游戏计划不再出现。
- `E2E-HOME-001`：首页完成事项后统计即时更新。
- `E2E-HOME-002`：备忘可转为今日计划或模块内容。

- `E2E-HOME-004`：今天要完成的学习、饮食两类具体计划全部显示，摘要和事项可跳转到正确详情。
- `API-HOME-003`：当前有效的学习目标即使没有拆分当日任务，也会出现在首页学习摘要中，未来尚未开始的目标不显示。
- `E2E-HOME-005`：首页概况只显示今日事项、已经完成和必须完成三张统计卡，不显示“逾期事项”卡。

- `API-SYNC-001`：模块事项按计划日期进入今日计划。
- `API-SYNC-002`：今日计划完成后来源状态同步。
- `API-SYNC-003`：来源完成后今日计划状态同步。
- `API-SYNC-004`：修改日期后只出现在新日期。

## PRD-10.5 模块功能

- `E2E-LEARN-001`：拆分章节、记录任务和学习情况并计算进度。
- `E2E-LEARN-002`：点击左侧目标可修改计划信息，右侧可随时保存 0—100 的手动进度。
- `E2E-LEARN-003`：每个学习目标和学习任务可点开修改或单独删除；取消删除保留草稿，失败可重试，处理中禁止重复提交及关闭，删除目标后选中剩余目标，最后一个删除后显示空状态。
- `E2E-LEARN-004`：小窗口和 DPR 2 下确认与取消按钮在视口内且可实际点击；修改任务排期、清空日期和删除后，首页、今日计划、搜索及刷新后的学习页同步，其他目标、任务与饮食不受影响。
- `API-LEARN-001`：删除目标级联软删除章节、任务、记录、资料及正反向关联日程；已完成、逾期及未来任务均消失，旧版本断链不残留，重复删除返回 404，其他目标和模块保留。
- `API-LEARN-002`：任务标题与日期修改同步日程，清空日期取消排期，重新排期复用旧关联且保留进度与备注；单删任务只移除自身及其日程，拒绝无效日期、跨目标章节和已删除目标的写入。
- `API-LEARN-003`：学习写入在成功响应发送前完成提交；ASGI 响应探针通过独立数据库会话验证新建、修改与删除立即可见，避免刚创建的目标无法安排任务或已删除目标被刷新回列表。
- `E2E-DIET-001`：按月历安排餐次并按当前月份生成可勾选购物清单。
- `API-DIET-001`：修改餐次后关联的今日计划标题同步更新，空饮食内容被拒绝。
- `E2E-DIET-002`：点击已有餐次格可修改饮食内容，点击空餐次格可按对应日期和餐次直接新建。
- `E2E-DIET-003`：周一开头的月历覆盖完整周，月份切换、回到今天、跨年和闰年边界正确；当天高亮，实际饮食可见，多餐可展开。
- `E2E-DIET-004`：单餐删除必须确认，取消不删除；删除后保留其他餐食，失败时保留原餐食和编辑窗口。
- `E2E-DIET-005`：1440×1000、508×590（DPR 2）和 390×590 下快速打开编辑器后，删除确认和取消按钮始终在视口内并可用鼠标点击；取消保留未保存内容，失败可直接重试，请求处理中禁止重复提交和关闭编辑器，成功后各模块及刷新后的日历均不再显示该餐食。
- `API-DIET-002`：编辑日期、餐次和实际饮食后，首页、今日计划和搜索同步；旧日期不再呈现该安排。
- `API-DIET-003`：删除待办/已完成餐食后，日历、首页、今日计划、搜索和逾期/即将到期统计不再呈现，其他餐食、菜品和健康记录保留，新购物清单排除该餐食食材。
- `API-DIET-004`：缺失关联 ID 或存在旧来源关联时，删除仍移除所有关联事项；从今日计划删除餐食也同步移除日历，只有显式恢复才重新呈现。
- `E2E-GAME-RETIRE-001`：左侧导航、快速新增、全局搜索、首页和今日计划均不显示游戏内容，访问旧 `/games` 地址返回首页。
- `API-GAME-RETIRE-001`：旧游戏娱乐接口不再注册，相关请求返回 404。
- `DB-GAME-RETIRE-001`：数据库从旧版本升级到 `0003` 后，现有 `game_plans` 及模块为游戏或来源为游戏计划的关联 `agenda_items` 均被软删除，非游戏事项不受影响。

## PUBLIC-13 可选多人网页

- `PUBLIC-AUTH-001`：未登录访问公开版数据接口返回 401；注册、登录、退出和重启后的会话有效，密码仅保存加盐哈希，跨站写入被拒绝。
- `PUBLIC-DATA-001`：两个账号的学习计划、饮食、搜索和备份完全隔离；公网服务不挂载本机主人数据库；错误账号令牌不能修改他人数据。
- `PUBLIC-AI-001`：访客无需安装 Ollama，生成请求由主机上的 `qwen2.5:1.5b` 完成；模型设置只由主机管理，并发和每日次数受限。
- `PUBLIC-BROWSER-001`：HTTPS 公网地址可以注册、登录、生成及导入真实模型计划并退出；启动登录页、窄屏布局和服务重启后访问正常。
- `PUBLIC-SEC-001`：路径穿越不能读取前端目录之外的文件；公开隧道只指向独立服务，原本的 `8765` 私人服务仍仅监听本机。

## 测试数据原则

- 自动测试只使用临时目录和临时 SQLite 数据库。
- 备份恢复测试只替换测试数据库。
- 每个测试独立创建数据，不依赖执行顺序。
- 不允许删除、跳过或放宽失败测试来通过验收。
