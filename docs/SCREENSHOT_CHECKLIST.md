# 使用指南截图清单

用于配合[使用指南](USER_GUIDE.md)。当前均待提供，不复用旧版页面图来代表当前版本，也不据截图推断测试已通过。

## 优先提供的页面

| 编号 | 页面或状态 | 画面需要包含 |
| --- | --- | --- |
| S01 | 登录页面 | 应用名称、用户名/密码输入框、登录与创建个人空间入口；不要填写真实密码 |
| S02 | 首页总览 | 左侧导航、今日统计、已有学习或饮食摘要、完成进度；不要求把整张长页面挤在一图中 |
| S03 | 今日计划 | 必须完成、按时间安排、有空再做等分组；含学习/饮食来源标识与完成状态。编辑窗口可另发一张 |
| S04 | 学习目标详情 | 示例目标、阶段、任务、日期、预计分钟、进度及专注入口 |
| S05 | 编辑学习任务 | 任务名称、说明、所属阶段及新增/修改阶段入口、保存按钮 |
| S06 | AI 学习草稿预览 | 已生成的阶段与任务、日期和时间、确认加入入口；较长时拆成上下两张 |
| S07 | 饮食日历 | 当前月份、不同日期的餐食以及可见的餐次/热量 |
| S08 | 多菜品餐食编辑 | 至少两种食物、输入补全或已选菜品、用量及整餐热量；可拆成输入区、估算明细两张 |
| S09 | 日常记录 | 同一天多次记录后按类型归组；建议有两条学习、一条运动、一条饮食，并保留日期和修改入口 |
| S10 | 大模型设置 | 实际运行方式下的模型来源、模型名称、连接成功状态及保存/切换入口 |
| S11 | 回收站 | 学习、饮食等大类；展开一个学习目标或购物清单，显示整组和逐条恢复入口 |
| S12 | 备份记录 | 立即备份入口、备份时间、手动/恢复前自动备份标识、恢复入口；本地用户路径可遮挡 |

## 拍摄与提交

- 使用当前准备提交的版本，先选定完整本机版或共享网页版；若两种都拍，请说明每张的运行方式。
- 使用演示账号和示例数据。不要展示密码、密钥、令牌、私人笔记或同学个人信息。
- 尽量保持窗口大小、缩放和主题一致，显示清晰文字、关键按钮与页面标题。
- 弹窗内容较长时分上下两张，无需缩小到文字难以辨认；不要裁掉必要的操作按钮。
- 可以直接在聊天中分批发送，并附编号；不要求自行处理文件名。可先发 S02、S03、S04、S07、S09、S10。
- 收到后将按页面核对说明、补充图注并将图片保存到 `docs/images/user-guide/`。未收到的截图继续标为待补，不放置失效图片链接。

## 可一并说明的信息

截图时的版本或提交号、运行方式、操作系统和浏览器。测试耗时、成功率及修复效果需要另外实际测量，不能只根据截图填写。
